# OpenStore

Open-source e-commerce storefront on Next.js — products, collections, cart,
and admin actions, with localization built in.

- Auth: Better Auth (email + OAuth)
- Data: Drizzle ORM + Neon Postgres · product images on Vercel Blob
- Email: Resend + React Email
- UI: Tailwind + shadcn/ui, dark mode
- i18n: route-based locales (`/en`, `/es`)

Copy `.env.example` to `.env`, install deps, and run the dev server.
